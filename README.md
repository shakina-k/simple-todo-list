To-Dolist web application<br>
A simple To-Do list web application that helps users to stay organize and keep track of their tasks. <br>

Features<br>
Add Task - User can enter and add new tasks to the list. <br>
Task List- Displays list of task to complete. <br>
Delete Task - Allows users the option to check off tasks once completed.<br>
Responsive Design - Works on desktop, tablet, and mobile devices.<br>

Technologies Used:<br>
HTML <br>
CSS<br>
Javascript<br>
